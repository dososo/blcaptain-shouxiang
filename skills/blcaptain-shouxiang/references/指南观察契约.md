# 指南观察契约（指南观察/1.0）

宿主看完照片后写一份 `观察记录.json`，交给 `palm.py 指南`。用户不手填。完整样例见 [指南观察示例](指南观察示例.json)（合成，只用于结构测试）。

## 顶层

| 字段 | 必填 | 说明 |
|---|---|---|
| `schema_version` | 是 | 固定 `指南观察/1.0`，不符直接拒绝 |
| `照片` | 是 | `{"文件","宽","高"}`，宽高为原照像素 |
| `基本.手别` | 否 | `{"值":"左手/右手","状态":"确认/推断","依据"}`；镜像不明写「推断」 |
| `基本.拍摄` | 否 | 一句话：光线、遮挡、哪些部位没入镜 |
| `用户自述` | 否 | 用户主动说的话，单独放；脚本不拿它改观察。可填 `年龄`（整数），只用来在人生阶段标「你在这里」，不改任何断语 |
| `特征` | 是 | 数组，见下 |
| `冲突` | 否 | 本次判读与旧判读不一致时写：`对象/本次判读/旧判读/依据/处理`，只进依据层 |

## 特征

每项：`id`（唯一）、`类别`、`状态`、`属性`、`描述`，以及定位（`路径` 折线 / `点` / `区域`[x,y,r] 三选一，坐标为相对原照宽高的 0—1 比例）和可选 `局部`（原照像素框 [x0,y0,x1,y1]，用于局部图）。

`状态` 只能是四个值，决定权重：

| 状态 | 权重 | 什么时候用 |
|---|---|---|
| 清楚 | 1.0 | 全段看得清 |
| 部分 | 0.7 | 能看出主体，部分变浅、断续或被遮 |
| 不清 | 0.3 | 只能看到一点影子；脚本不下断，只给补拍句 |
| 未见 | 0 | 照片里没有或没入镜；脚本给补拍句 |

## 属性取值（只有这些值会命中断语）

属性值必须照下表写原词；写别的值不会报错，但这一处会显示「看清了，但不在本库断法里」。新增取值要先在 [指南断语库](指南断语库.json) 加规则并跑 `scripts/guide_checks.py`。

| 特征 id | 属性：可选值 |
|---|---|
| 感情线 | 长度：长；终点：食中指缝；走向：掌缘低、向食中指间上扬；交会：中段有细纹交会 / 分支多 |
| 智慧线 | 起点：与生命线同源；长度：中 / 长；走向：平缓下斜；末段：交会变浅 |
| 生命线 | 弧度：宽；中段：杂纹交叉；末端：掌根中部 |
| 事业线 | 起点：掌心；连续：断续；上段：未贯指 / 贯指（贯指须状态为清楚） |
| 健康线 | 交会：与感情线相接（只要清楚或部分即有一条基础断） |
| 掌形 | 长宽：长方；厚薄：厚；纹理：细纹密；指掌比：指短于掌 |
| 掌心 | 形态：四周丰中间浅 |
| 掌色 | 整体：红润偏赤；分布：边缘红掌心浅 |
| 金星丘、月丘 | 饱满：饱满 |
| 坎宫 | 色：泛红 |
| 巽宫、离宫、坤宫 | 饱满：较满 / 平满 / 平 / 缺（驱动人生阶段） |
| 拇指 | 粗细：粗长；外张：大 |
| 小指 | 外张：明显 |
| 四指 | 指节：平顺 |
| 中指指腹 | 纹样：斗形候选 |
| 腕纹 | 道数：两道清楚 |

**掌上年龄尺**要求事业线、智慧线、感情线、腕纹四项都是清楚或部分，并且都有 `路径`；缺任一项，人生阶段就退回〈相三主〉三段。路径要沿真实纹路描，起止点直接决定起势、线淡的岁数。

`太阳线`、`婚姻线` 等没入镜的部位也写进来，状态填「未见」，报告会提示补拍，而不是空着。

## 五行手型

脚本按掌形、手指、掌色等属性给金木水火土打分，取最高为主、次高为副；规则在断语库 `五行手型`。宿主不用自己判五行。另有部分取值只参与五行打分、不出断语（如掌形长宽「方」、厚薄「薄」、指掌比「指长于掌」、掌色整体「偏白」「偏黄」），全表见断语库 `五行手型.权重`。

## 不允许

- 没看清的不补造；不为栏目齐全硬认纹。
- 换问事、换日期都不得改写本文件；本文件只记照片所见。
- 不把指腹细嵴、细节点或身份模板写进来；只写斗/箕/弓候选。
