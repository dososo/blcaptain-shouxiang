# 掌中有话 · 手相指南

交付一份单文件 HTML，像算命先生当面讲给你听：先给结论（签、财运、身体、感情各一句），再给指数、要注意的月份、人生阶段，最后逐条讲每条纹、每根手指看到了什么、怎么断。方法、规则编号和出处全部收进页底折叠的「依据与方法」，正文不出现。

脚本不内置视觉模型：照片由宿主看，脚本只处理宿主写的观察记录。用户不手填 JSON。

## 完成流程

1. **查看原照。** 确认能看到图；看不到就请用户重发。全不可辨只给补拍指引。不必先问年龄、性别、职业。
2. **逐处观察并写记录。** 按[指南观察契约](references/指南观察契约.md)写 `观察记录.json`：每条纹、掌形、掌心、掌色、掌丘、三宫（巽离坤）、拇指、小指、四指、指腹、腕纹各一项；属性用契约表里的原词；没入镜的写「未见」，看不清的写「不清」。不补造、不硬认纹。前后判读不一致时写进 `冲突`。
3. **生成。** 输出目录须在技能目录外、父目录存在、自身不存在：
   ```bash
   python3 "技能目录/scripts/palm.py" 指南 --输入 "观察记录.json" --原照 "原照.jpg" --输出 "新的报告目录" [--问事 "今年财运"] [--日期 2026-11-03]
   ```
   输出 `掌中有话.html`（单文件，原照内嵌，离线可开）、`内容.json`、`回放.json`。回放时传原日期，内容摘要应一致。日期须在断语库「覆盖」范围内（2025-01-01 至 2035-12-31），超出时脚本报错停下，不生成半份报告。
4. **自查后交付。** 打开 HTML 看首屏是否就是结论；只把 HTML 交给用户。不做 PDF、不做社媒卡、不发布到任何平台。原照与报告是用户私人资产，不公开、不上传。

## 内容口径

- **这是娱乐算命，不是科普。** 话说直白：哪几个月进财、哪几个月防破财、哪几个月最容易上火、桃花在哪几个月、人生哪一段最累哪一段收获。不在每段重复免责声明；页脚一句「图一乐，身体不适请就医」即可。
- **断从哪来分四层，在依据层标清：** 古籍（〈论手〉〈相三主〉〈四季纹〉等）、近代（手相学通行讲法）、民间（平台通行说法）、合参（本项目把手型五行与节气月令生克相配，用来排流年流月）。合参是本项目自己的玩法，不说成古法。
- **指数**每项从 60 起算，按命中规则加减，限定在 45—95；80 分及以上标「吉」，60—79 标「平」，60 以下标「慎」。
- **身体只给生活提醒**（上火、睡眠、肠胃、久坐腰腿等），配「长期不适去体检/就医」；不写具体病名确诊、不写发病日期。
- **钱只给守财/破财/进财月份的娱乐提醒**，不给投资、借贷、买卖建议。
- 无恐吓、无「错过就倒霉」、无付费消灾或化解。
- **人生阶段按掌纹分段**：沿事业线量岁数（近代流年一派：腕纹 1 岁、交智慧线 35 岁、交感情线 50 岁），起点、交会、变淡处就是转折岁数，原照上画出年龄尺；五十岁后按〈相三主〉离宫、坤宫定转运方向。四条线缺一条就退回三主三段。用户主动说了年龄，只标「你在这里」。
- 换问事只改快速总结的先后顺序，不改观察与断语；换日期只改流年流月。

## 隐私

- 原照、指腹局部、问事和观察记录都是用户私人资产：只在本机生成，不上传、不公开。
- 指腹只记录粗略斗形、箕形、弓形候选或「未辨清」，不提取细节点、完整嵴线或身份模板。

## 检查

断语、指数加减、月令与神煞都在[指南断语库](references/指南断语库.json)；改库或改脚本后运行：

```bash
python3 "技能目录/scripts/guide_checks.py"
python3 "技能目录/scripts/refresh_manifest.py"
python3 "技能目录/scripts/palm.py" 诊断
```

同输入同日期两次生成逐字节一致。合成记录只验证数据分支与版式；真人照片需要授权与人工对照。
